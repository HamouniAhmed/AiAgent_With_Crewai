# CrewAI Agent Orchestration

This project explores the capabilities of the [CrewAI](https://github.com/crewAIInc/crewAI) framework to orchestrate role-playing, autonomous AI agents. By fostering collaborative intelligence, CrewAI empowers agents to work together seamlessly to tackle complex tasks.

##  Overview

The goal of this project is to build and experiment with multi-agent systems using CrewAI. It includes examples of:
- Defining specialized Agents with unique roles and tools.
- Creating detailed Tasks for agents to execute.
- Orchestrating a Crew to manage the workflow and process.
- Integrating with `agentops` for monitoring and observability.

##  Prerequisites

- **Python Version**: Recommended Python 3.10 to 3.12.
  > [!IMPORTANT]
  > Note: CrewAI 0.95.0 has a dependency constraint that requires Python < 3.13. If you are using Python 3.13+, consider upgrading CrewAI or using a Python 3.12 environment.
